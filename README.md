A one-page front page summing up **Monday 23 November 2026** in one image: 31 stories across 6 regions.

- **Heroes:** AI rout hits Asia (Kospi −3.3% to 4,708.54) · Guterres urges AI rules at the Bridgetown summit (150 delegates back a risk framework) · US lead over China at a record low (Asia Power Index 2026: US 78.9, China 73.6, gap 5.3).
- **10 cards + 18 ALSO stories**, a world map with numbered pins, a number strip, and a red DATE CHECK box that keeps out stories dated before 23 Nov.
- **Chips:** REPORTED = confirmed by wires · CLAIM = one side's claim, not independently confirmed.

## Run it

```sh
python3 draw.py        # regenerate entry.png (1024x1024)
MAKEFUN_OUTPUT_DIR=out python3 main.py   # copy entry.png to out/entry.png
```

`main.py` is stdlib-only and writes only to `$MAKEFUN_OUTPUT_DIR/entry.png`.
